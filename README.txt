# Final Letter Website

## Open locally
1. Open this folder in VS Code.
2. Put your real photos inside `assets/`.
3. Use these exact filenames, or change the filenames in `index.html`:
   - family.jpg
   - future.jpg
   - better-half.jpg
   - pondicherry.jpg
   - pondicherry-hug.jpg
   - pondicherry-night.jpg
   - arunachalam.jpg
   - anniversary.jpg
   - first-salary.jpg
   - ahmedabad.jpg
   - beautiful-life.jpg
4. Open `index.html` with Live Server in VS Code.

## Hosting
The site uses only HTML/CSS/JS and local images, so it can be hosted on GitHub Pages, Netlify, Vercel, etc.

## Important
The Google Fonts connection is optional. If you want the site to work with no external requests, remove the Google Fonts `<link>` tags from `index.html`; the CSS has fallbacks.

The mobile screen is intentionally blocked. This is designed for desktop.
